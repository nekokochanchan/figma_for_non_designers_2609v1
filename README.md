# Figma for Non-Designers

A responsive single-page quick-start guide for business stakeholders. Built with React, Vite and Tailwind CSS. No backend, authentication, database or external API calls in the frontend.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Page content and simple reusable components are in `src/main.jsx`. Styling and responsive rules are in `src/style.css`. Illustrations are made from HTML/CSS and Lucide icons, with no external image requests.

The prototype and Follow examples are educational simulations. Exercise checkboxes reset when the page reloads. Status names such as Latest / Approved are team conventions, not automatic Figma approval guarantees.
